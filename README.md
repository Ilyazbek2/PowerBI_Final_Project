# Power BI Sales & Business Analytics Dashboard



## 📌 Dashboard Pages

- **Sales & Profitability** — sales, cost, profit, margin and product categories
- **Logistics & Warehouses** — warehouse stock, revenue and delivery costs
- **Customers & Regions** — customers, orders, regions and average order value
- **Employees & Efficiency** — employees, salaries, hiring and revenue per employee

## 🛠️ Tools

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
